## What it is

A static guide site for D2R players: skill trees, meta builds, gear plans and leveling/endgame tips for all eight classes, plus six guide topics covering runewords, Terror Zones, Uber endgame and more.

Pure HTML + CSS + vanilla JS — no framework, no backend, no third-party libraries. Every page is generated by a single Python script, `build_site.py`, and the content is up to date with Patch 3.3 / Ladder Season 15.

## Features

- **All eight classes** — Amazon, Sorceress, Necromancer, Paladin, Barbarian, Druid, Assassin and Warlock; each page has skill allocations, build cards and practical tips
- **Six guide topics** — Runewords codex, leveling, Terror Zones & Sunder, Uber endgame, general tips, farming & MF
- **One-click bilingual toggle** — the `EN / 中文` button in the top bar, remembered via localStorage
- **Season-current content** — built around the Patch 3.3 / Season 15 meta (tighter Sunder access, reworked leveling uniques, the risen Warlock Sigil: Death build, and more)
- **Pure static, zero deps** — no frameworks or build tools; clone it and open `index.html`
- **Single data source** — all pages come from one script, `build_site.py`; edit and re-run
- **Dark gold theme** — hand-written CSS; every icon is a Unicode character, no game art assets

## Quick start

### Use it online

Click **[Use it online](https://kingsir.work/D2/)** to open it — nothing to install, no sign-up. There is also a **[GitHub Pages mirror](https://isnotry.github.io/D2/)**, which redirects to the main site.

### Run it locally

```bash
git clone git@github.com:isnotry/D2.git
cd d2
python3 -m http.server 8000
# Open http://localhost:8000
```

Opening `index.html` directly in a browser works just as well.

## Regenerating the site

Every page is generated by `build_site.py`; edit the script and re-run to overwrite the output:

```bash
python3 build_site.py
```

Output: `index.html`, `classes/*.html`, `guides/*.html`, `css/style.css`, `js/main.js`.

How bilingual works: body text goes through `bi(chinese, english)`, which emits a `.zc` and an `.ec` `span`; CSS shows one side based on `<html class="en">`. Game terms have a dedicated zh/en glossary (`ZH_PAIRS`) and are rewritten automatically.

## Development notes

- Edit content only in `build_site.py` — never hand-edit the HTML, it gets overwritten on regenerate
- Use `bi(chinese, english)` for new copy; add game terms to the `ZH_PAIRS` glossary to make them bilingual automatically
- Don't take apart the `.zt` structure: the show/hide under `html.en` relies on the `.zc` / `.ec` class names
